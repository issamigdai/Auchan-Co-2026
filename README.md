# Auchan-Co-2026
Création d'un site web moderne et réactif pour le Centre Commercial AUCHAN, optimisant l'expérience d'achat en ligne avec une interface fluide. Le site proposera des filtres intuitifs, une gestion facile du panier, et la possibilité de personnaliser les achats et ainsi que d'autres fonctionnalités que vous découvrirez en consultant notre brief
